# Legal Maxims Studio

A no-dependency visual web app for learning legal maxims and legal phrases from basic to advanced level.

## Live Use

This app can be opened directly in a browser by double-clicking:

```text
index.html
```

## Run

Open PowerShell in this folder and run:

```powershell
.\run.ps1
```

Then open:

```text
http://localhost:8000/
```

If PowerShell blocks local scripts, run:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

You can also open `index.html` directly in a browser.

## Features

- Explore mode with search, category, and level filters.
- Flashcards for quick revision.
- Quiz mode with score tracking.
- Matching game for maxim-to-meaning practice.
- Legal maxims grouped across criminal law, torts, contracts, equity, evidence, procedure, public law, interpretation, property, and conflict of laws.

This is a study tool, not legal advice.
